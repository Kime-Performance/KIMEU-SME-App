Use the existing Google Drive folder for each Foundations and Advanced workshop's presentations. Each workshop subpage also needs a separate link for PDF files outside the presentation.

Google Slides is the intended main presentation source. PDFs and still images are supporting materials, not the primary presentation format.

**Why:** The user already maintains workshop presentation folders in Drive and explicitly chose linking those folders rather than uploading duplicate decks.

**How to apply:** Keep presentation-folder access separate from PDF/handout access. A folder link opens Drive; the SME then selects a presentation and starts its slideshow. Do not imply opening a folder automatically enters presentation mode.
