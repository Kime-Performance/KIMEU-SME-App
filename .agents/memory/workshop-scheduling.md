Foundations workshops each occur a few times during the year and need a time point. Advanced workshops typically occur on different days in different locations to reach the variable regions. The KIMEU calendar is typically set ahead of the year, but workshop dates sometimes shift last minute.

**Why:** The user described this operating process when asking how upcoming workshops should be scheduled and displayed.

The user confirmed that the team currently maintains the official KIMEU workshop schedule in Google Calendar.

The user confirmed: "Google calendar one way to reference occurence, do not take calendar attendance as real attendance, SME will take that real time in the app."

**Why:** Calendar occurrences supply scheduling context, not evidence of attendance.

**How to apply:** Use a one-way Calendar connection for scheduled occurrences. Never import invitations, guests, or RSVPs as actual attendance. SMEs record actual attendance live in the app. Account for multiple dated offerings per workshop, regional locations, and rescheduling.

Practical scheduling must allow dates within two weeks after a workshop, across all workshops, rather than one finite date.

**Why:** The user clarified that the allowance is about scheduling, not green coloring, said it should apply to all workshops, and explicitly chose "Allow scheduling within two weeks."

**How to apply:** Permit today/future planned dates from workshop day through day 14 inclusively. Keep plans separate from actual completion evidence: scheduling must not mark attendance, Pass/Fail, a practical completion date, or K-Star. Preserve actual-date validation and allow recording late completed practicals. The Calendar connection remains one-way; planning does not create Google Calendar events.

When a PT has multiple dated occurrences of the same workshop, show one practical record at a time and require an explicit session selection.

**Why:** The user interpreted multiple saved KB occurrences as duplicate RD practical requirements. Silently choosing the latest could instead put a sign-off on the wrong occurrence.

**How to apply:** Keep all occurrence history and highest-earned K-Star evidence. Do not delete or merge sheet records to resolve this display confusion. Preserve draft-loss warnings when switching the session being edited.

The user chose Foundations and Advanced workshops only for the app's upcoming list, not all KIMEU Calendar events.

**Why:** The user selected this scope explicitly.

**How to apply:** Exclude general recurring education meetings from the upcoming workshop list.

The new Foundations workshops are planned for 2027, not currently in KIMEU Calendar. On October 23, 2026, the user said the schedule would be set in about a month.

**Why:** The user clarified that missing new Foundations events are expected, not a connection or matching problem.

**How to apply:** Do not infer missing workshops or commit dates from existing events. The current scope is only the Calendar connection; do not proceed with date setup, workshop mapping, or session-linking features until requested.
