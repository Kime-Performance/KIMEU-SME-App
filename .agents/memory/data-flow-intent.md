---
name: Roster and workshop data directions
description: User-defined source systems and one-way data flow for SME operations.
---

The KIME Master Database's Roster tab is the continuing source of PTs available for selection in the SME app. This direction is read-only: roster sheet to app.

The SME opens a workshop subpage to record live attendance, check off PT completion, and write notes visible to the KIMEU director. These records flow from the app into the KIMEU Master Database for consistent Foundations and Fellowship pathway tracking.

**Why:** The user specified two one-way connections, with the shared sheets supporting the KIMEU Progress Tracker.

**How to apply:** Keep the roster source separate from the workshop-record destination, even if both ultimately reside in the same spreadsheet. Do not write roster changes back from this app. Distinguish individual PT completion from closing a workshop session, and verify the intended completion criteria before implementing sign-off.
